SK YT Upload

SK YT Upload is a private tool used only by the owner of the YouTube channel Kutty Kurangu Mittu (Story Kids). It uploads and schedules that channel's videos and adds them to the channel's playlists. It is not offered to anyone else.

Privacy policy

What it accesses. Using the YouTube API Services, and only with the channel owner's permission, it accesses that one channel's videos, playlists and related details.

How data is used. Only to run that channel.

Storage and sharing. The sign-in token and working files stay on the owner's own computer. Data is not sold or used for advertising, and is shared with no one except as needed to use Google's services.

Removing access. The channel owner can withdraw access at any time at Google security settings.

Google and YouTube. This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
