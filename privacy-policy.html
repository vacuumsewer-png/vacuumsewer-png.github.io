JAM Uploader

JAM Uploader is a private tool used only by the owner of the YouTube channel Just AI Minute. It schedules that channel's videos, manages their details, playlists and comments, and reads the channel's own analytics. It is not offered to anyone else.

Privacy policy

What it accesses. Using the YouTube API Services, and only with the channel owner's permission, it accesses that one channel's videos, playlists, comments and analytics.

How data is used. Only to run and improve that channel. Public comment text may be read so the channel can reply to it.

Storage and sharing. The sign-in token and working files stay on the owner's own computer. Data is not sold or used for advertising, and is shared with no one except as needed to use Google's services.

Removing access. The channel owner can withdraw access at any time at Google security settings.

Google and YouTube. This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
